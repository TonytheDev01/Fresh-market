# FreshBasket Market 🛒

A fully responsive same-day grocery delivery web app targeting the Nigerian market.

**Live Demo:** https://tonythedev01.github.io/Fresh-market/

## Features
- Dynamic product grid with category filters
- Location coverage checker
- Tiered delivery pricing
- Complete authentication modal (Sign In / Sign Up)
- Partner logo marquee
- Newsletter with discount capture
- Mobile app download section
- Fully responsive — mobile first

## Tech Stack
HTML5 · CSS3 · Vanilla JavaScript

## What This Demonstrates
- Production-level multi-section commercial UI
- Auth flows, modals, and interactive components without React
- Dynamic data rendering from JS data layer
- XSS-safe DOM manipulation
- Cross-browser CSS with proper fallbacks
